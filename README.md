
# Sistema de seguridad automatico
### Proyecto ACATEC
![thumbnaol](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTAzr_pbjMN3hPliXnIXGdfgL_IqgjH4aCcELiz3lg2ny_mkziavC6X-nZ0&s=10)
este es un sistema de seguridad que escanea automaticamente el perimetro en busqueda de peligros y reporta informacion.

## Que queremos hacer?
 - Un sistema de seguridad para aplicaciones de alto calibre como bases militares secretas, o un simple escaner de seguridad desarmado

## Cual es proposito del proyecto?

## Como esperamos que funcione?
 - el sensor ultrasonico mide la distancea, osea los intruzos, y el servo lo mueve para que escanee el perimetro.

## Modos
- Escaneo
	- Marca el perimetro y envia alertas sobre intrusos
- Alerta
	-  (similar a escaneo pero mas rapido)
- Alerta maxima
	- Escanea rapidamente el perimetro y dispara a los intrusos
